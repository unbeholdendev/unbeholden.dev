# Dateless `/blog/{slug}` URLs, CC BY prose, CC0 snippets

Entries live at `/blog/{slug}` with no date in the path, because a guide revised in two
years' time should not carry a stale year in a URL that other people have linked to. Prose
is licensed CC BY 4.0 and code snippets CC0/MIT, stated on the About page.

Both halves are recorded because both are effectively irreversible: URLs once linked cannot
move without breaking other people's pages, and a licence once relied upon cannot be
withdrawn.

## Considered options

`/{slug}` was rejected because every future page then becomes a reserved word.
`/{year}/{slug}` was rejected because dating the URL fights the idea of an entry that gets
maintained in place. `/writing/{slug}` was rejected as an affectation: the section is a blog
and calling it one costs the reader nothing.

All rights reserved was rejected as inconsistent with the site's own argument, and because
guides contain config and scripts that readers paste into production, where licence
ambiguity is a practical problem rather than an academic one. Attribution is retained on
prose and dropped on snippets, so the writing is credited and the configuration is free to
take.
